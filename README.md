# Quaero

*Ask the code.*

Quaero is an operator-driven source code analysis and application security research platform.

The project aims to provide researchers with a structured way to query source code, investigate program behavior, explore data flows, and examine security boundaries.

Rather than automatically reporting vulnerabilities, Quaero is designed to support the research process itself.

The initial development focuses on PHP applications.

## Development

Quaero is an independent, private-source project under active development.
